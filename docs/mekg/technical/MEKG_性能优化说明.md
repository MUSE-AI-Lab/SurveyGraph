# MEKG性能优化说明

## 🚀 最新优化（2025-11-16）

针对测试中发现的问题进行了以下优化：

### 问题1: 搜索结果太少（33篇 vs 100篇目标）

**优化方案**:
1. ✅ **3倍搜索配额**: 每个关键词搜索3倍数量
2. ✅ **启用模糊搜索**: `fuzzy_search=True` 获取更广泛结果
3. ✅ **雪球采样扩展**: 如果搜索不足，自动使用前50篇作为种子进行雪球采样
   - 获取被引用论文 (`cites:paper_id`)
   - 直到达到目标数量

**预期效果**: 搜索50篇 → 实际获取150篇候选 → 雪球采样补充 → 确保有足够PDF候选池

---

### 问题2: PDF下载慢且成功率低

**优化方案**:
1. ✅ **提高并发**: 从10提升到20线程
2. ✅ **减少超时**: 从30秒降到20秒（快速失败）
3. ✅ **减少重试**: 从3次降到2次
4. ✅ **加快重试**: 指数退避改为固定0.5秒
5. ✅ **降低PDF最小要求**: 从10KB降到5KB
6. ✅ **增强arXiv识别**: 支持版本号和标题中的ID
7. ✅ **减少延迟**: 论文间延迟从0.5秒降到0.1秒

**预期效果**: 下载速度提升约3倍，成功率提升（更多arXiv源）

---

### 问题3: API限流（429错误）

**优化方案**:
1. ✅ **分离并发策略**:
   - PDF下载: 20并发 ✅ （无需API调用）
   - PDF解析: 20并发 ✅ （无需API调用）
   - 属性提取: 30并发 ✅ （LLM API）
   - 关系提取: 30并发 ✅ （LLM API）

2. ✅ **保留现有限流措施**:
   - 属性提取每10个请求延迟1-2秒
   - 指数退避重试机制

**预期效果**: 平衡速度和稳定性，避免API封禁

## 💡 关键优化思路

1. **论文搜索**: 宁可多搜不可少搜 → 3倍配额 + 雪球采样
2. **PDF下载**: 快速失败快速重试 → 高并发 + 低超时 + 快重试
3. **LLM调用**: 稳定第一速度第二 → 中等并发 + 延迟 + 重试
