# MEKG 系统架构总结

## 1. 图数据库与图计算

### 1.1 图数据库
**使用技术**: Memgraph (兼容 Neo4j Cypher 语法)

**核心特点**:
- 高性能图数据库，支持实时查询
- 原生 Cypher 查询语言
- 内存优先架构，查询速度快

### 1.2 图计算引擎
**使用技术**: python-igraph

**核心特点**:
- C语言实现，性能比 NetworkX 快 **100倍**
- 支持 Louvain/Leiden 社区检测算法
- 支持 PageRank、Betweenness Centrality 等图算法

**社区检测实现** (`src/modules/mekg/igraph_adapter.py`):
```python
# Louvain 算法调用
communities = undirected.community_multilevel(weights=edge_weights)
```

**支持的算法**:
| 算法 | 方法 | 说明 |
|-----|------|------|
| Louvain | `community_multilevel()` | 默认算法，快速高效 |
| Leiden | `community_leiden()` | 更精确，需要 leidenalg |
| Infomap | `community_infomap()` | 基于信息流 |
| Label Propagation | `community_label_propagation()` | 最快但精度较低 |

## 2. 知识体系结构

### 节点类型 (Nodes)

| 节点类型 | 说明 | 关键属性 |
|---------|------|---------|
| **Paper** | 学术论文 | id, title, abstract, year, citations, community_id |
| **Topic** | 研究主题 | name, description |
| **Community** | 论文社区 | id, name, paper_count |
| **SemanticEntity** | 语义实体 | name, type (Method/Task/Dataset/Metric) |

### 关系类型 (Relationships)

| 关系类型 | 说明 | 方向 |
|---------|------|------|
| **CITES** | 引用关系 | Paper → Paper |
| **SEMANTIC_RELATION** | 语义关系 (extends/improves/applies等) | Paper → Paper |
| **BELONGS_TO** | 归属主题 | Paper → Topic |
| **PROPOSES** | 提出方法/实体 | Paper → SemanticEntity |
| **USES** | 使用方法/数据集 | Paper → SemanticEntity |

## 4. Graph-RAG 搜索机制

### RAG 使用位置

**搜索阶段** (`graph_rag_searcher.py`):

```
用户查询 → 语义向量化 → 向量相似度匹配 → 图结构扩展 → 排序返回
```

### 搜索类型

| 类型 | 说明 | 适用场景 |
|-----|------|---------|
| **Semantic** | 向量相似度搜索 | 模糊查询、概念搜索 |
| **Keyword** | 关键词精确匹配 | 精确查找特定论文 |
| **Hybrid** | 混合搜索 (推荐) | 综合场景 |

### 向量化模型

- **模型**: `all-MiniLM-L6-v2` (Sentence Transformers)
- **输入**: 论文标题 + 摘要前500字
- **输出**: 384维向量

## 5. 大图谱 → 小图谱提取

### 提取策略

```
┌─────────────────────────────────────────────────────────────┐
│                    子图提取流程                              │
└─────────────────────────────────────────────────────────────┘

1. 种子论文识别
   ├── 语义搜索: 向量相似度 Top-K
   └── 关键词搜索: 标题/摘要匹配

2. 图结构扩展 (N-hop)
   ├── 直接关系: CITES, SEMANTIC_RELATION
   ├── 共享实体: 通过 SemanticEntity 连接
   ├── 共享主题: 通过 Topic 连接
   └── 同社区: community_id 相同

3. 智能裁剪
   ├── 社区感知: 优先保留种子论文所在社区
   └── 重要性排序: citations × 0.6 + freshness × 0.4

4. 输出子图
   └── 节点 + 边 + 社区信息
```

### 关键参数

| 参数 | 默认值 | 说明 |
|-----|-------|------|
| `max_papers` | 100 | 最大论文数 |
| `expand_hops` | 2 | 扩展跳数 |
| `community_aware` | true | 社区感知裁剪 |

## 6. 子图驱动 Survey 写作

### 写作流程

```
┌─────────────────────────────────────────────────────────────┐
│                 Survey 生成流程                              │
└─────────────────────────────────────────────────────────────┘

1. 子图获取
   └── 调用 /rag/subgraph API 获取相关论文子图

2. 结构分析
   ├── 社区 → 章节划分
   ├── 引用关系 → 时间线/演进脉络
   └── 语义关系 → 方法对比/改进关系

3. 内容生成 (LLM)
   ├── 摘要: 基于子图整体信息
   ├── 引言: 基于高引用种子论文
   ├── 相关工作: 按社区/主题分组
   ├── 方法对比: 基于 SEMANTIC_RELATION
   └── 结论: 基于 limitations 和趋势

4. 引用管理
   └── 自动生成 BibTeX 引用
```

### 子图信息利用

| 子图元素 | Survey 用途 |
|---------|------------|
| **社区** | 章节划分、主题分组 |
| **中心论文** | 重点介绍、引言素材 |
| **CITES 关系** | 时间演进、影响力分析 |
| **SEMANTIC_RELATION** | 方法对比、改进关系 |
| **SemanticEntity** | 术语表、方法分类 |
| **citations** | 重要性排序 |
| **year** | 时间线构建 |

## 7. API 接口

### 核心端点

| 端点 | 方法 | 说明 |
|-----|------|------|
| `/rag/search` | GET/POST | Graph-RAG 搜索 |
| `/rag/subgraph` | GET/POST | 子图提取 |
| `/rag/suggest` | GET | 搜索建议 |
| `/build` | POST | 启动构建任务 |
| `/graph/visualize` | GET | 图谱可视化数据 |

### 搜索请求示例

```bash
# 搜索
curl "http://localhost:8000/rag/search?query=transformer&max_results=50&search_type=hybrid"

# 子图提取
curl "http://localhost:8000/rag/subgraph?query=attention+mechanism&max_papers=100&expand_hops=2"
```
