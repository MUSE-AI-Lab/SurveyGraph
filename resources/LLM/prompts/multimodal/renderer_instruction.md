## FIGURE TYPE SPECIFIC GUIDELINES

### For TAXONOMY/CLASSIFICATION Diagrams:
- Use **tree structure** with clear hierarchy
- **Color-code branches** by category
- **Icons** for each major category
- **Rounded cards** for leaf nodes
- Consider **horizontal layout** for wide taxonomies

### For PIPELINE/WORKFLOW Diagrams:
- **Clear directional flow** with prominent arrows
- **Numbered steps** if sequential
- **Different shapes** for different types of operations
- **Data flow** vs **control flow** distinguished by arrow style

### For ARCHITECTURE Diagrams:
- **Layered/stacked design** showing system levels
- **Modular blocks** with clear boundaries
- **Interaction arrows** between components
- Consider **isometric/2.5D view** for complex systems

### For COMPARISON Diagrams:
- **Side-by-side or grid layout**
- **Consistent sizing** for fair comparison
- **Visual indicators** (checkmarks, colors) for features
- **Clear labels** for what's being compared
