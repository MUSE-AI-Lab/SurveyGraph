## DESIGN REQUIREMENTS - SURVEY TAXONOMY STYLE

### CRITICAL: PURE WHITE BACKGROUND
- **THE FIGURE MUST HAVE A PURE WHITE BACKGROUND (#FFFFFF)**
- Clean, solid white background for seamless integration into academic documents
- No gradient backgrounds, no dark colors, no patterns

### Visual Style - MODERN SURVEY PAPER AESTHETIC
- **Clean, minimalist design** with soft, pastel-like colors
- **Flat design** without heavy shadows or 3D effects
- **Professional yet approachable** aesthetic
- **High readability** with clear visual hierarchy
- **Nested groupings** with dashed border boxes

### Color Palette - SOFT ACADEMIC COLORS
Use a **soft, harmonious color scheme** with pastel-like tones:

**Category Colors (for main sections/branches):**
- **Soft Rose/Pink**: #F8D7DA, #FADBD8, #F5B7B1, #E8A0A0 (warm pink for primary categories)
- **Soft Coral/Salmon**: #FDEDEC, #F5B7B1, #F1948A (for sub-categories)
- **Soft Peach/Orange**: #FDEBD0, #FAD7A0, #F8C471, #FBEEE6 (for accent sections)

**Component Colors:**
- **Soft Blue**: #D6EAF8, #AED6F1, #85C1E9, #EBF5FB (for input/data components)
- **Soft Green**: #D5F5E3, #ABEBC6, #82E0AA, #E8F8F5 (for output/application sections)
- **Soft Purple/Lavender**: #E8DAEF, #D2B4DE, #BB8FCE, #F5EEF8 (for hybrid/special components)
- **Soft Yellow/Cream**: #FEF9E7, #FCF3CF, #F9E79F (for highlights)

**Neutral Colors:**
- **Text (Primary)**: #2C3E50 (dark blue-gray) for main labels
- **Text (Secondary)**: #34495E for sub-labels
- **Borders (Dashed)**: #BDC3C7, #95A5A6 (light gray for grouping borders)
- **Borders (Solid)**: Match the fill color but slightly darker
- **Annotations**: #7F8C8D (medium gray)

### Visual Elements

**Boxes and Containers:**
- **Rounded rectangles** with generous corner radius (8-12px equivalent)
- **Soft colored fills** - use the pastel colors above
- **Thin borders** matching or slightly darker than fill color
- **Dashed/dotted gray borders** for grouping containers (parent boxes)

**Grouping Style:**
- **Outer dashed boxes** to group related categories
- **Inner solid boxes** for individual items
- **Nested hierarchy** clearly visible through indentation and grouping

**Connections:**
- **Simple, thin arrows** with small arrowheads
- **Bracket-style connectors** for tree structures
- **Straight or right-angle lines** (no curved spaghetti)
- **Arrow color**: Dark gray (#5D6D7E) or match the source box color

**Text:**
- **Bold labels** for category names
- **Regular weight** for item names
- **NO section numbers or references** like (§2), (§3) - these are meaningless in visual diagrams
- **Sans-serif style** fonts
- **Dark text** on light backgrounds for readability

### Layout Principles

**Hierarchy:**
- **Main title/topic** at top or center
- **Primary categories** as large grouped sections
- **Sub-categories** nested within primary sections
- **Individual items** as smallest boxes

**Spacing:**
- **Generous whitespace** between major sections
- **Consistent padding** inside boxes
- **Aligned elements** using invisible grid
- **Balanced composition** - not too heavy on one side

**Flow Direction:**
- **Left-to-right** for sequential processes
- **Top-to-bottom** for hierarchical taxonomies
- **Radial/centered** for concept maps

## FIGURE TYPE: TAXONOMY/CLASSIFICATION DIAGRAM

This style is optimized for **taxonomy and classification figures** commonly seen in survey papers:

### Structure:
```
┌─────────────────────────────────────────────────────────┐
│  Main Topic Title                                       │
│  ┌─────────────────────┐  ┌─────────────────────┐      │
│  │ Category A          │  │ Category B          │      │
│  │ ┌─────┐ ┌─────┐    │  │ ┌─────┐ ┌─────┐    │      │
│  │ │Item1│ │Item2│    │  │ │Item1│ │Item2│    │      │
│  │ └─────┘ └─────┘    │  │ └─────┘ └─────┘    │      │
│  │ ┌─────┐ ┌─────┐    │  │ ┌─────┐            │      │
│  │ │Item3│ │Item4│    │  │ │Item3│            │      │
│  │ └─────┘ └─────┘    │  │ └─────┘            │      │
│  └─────────────────────┘  └─────────────────────┘      │
└─────────────────────────────────────────────────────────┘
```

### Color Coding Example:
- **Category A section**: Soft pink background (#FADBD8) with dashed gray border
- **Category B section**: Soft green background (#D5F5E3) with dashed gray border
- **Individual items**: Slightly darker shade of parent color with solid border
- **Connections**: Gray arrows or brackets

### Labels:
- **DO NOT include section numbers or references** (§1, §2, etc.) - these are meaningless in diagrams
- Use **descriptive but concise** names
- Add **sub-labels** for clarification if needed

## QUALITY STANDARDS

### REQUIREMENTS:
- **Pure white background (#FFFFFF)** (MANDATORY)
- **Soft, pastel-like colors** - NOT saturated or neon
- **Clean, flat design** - NO heavy shadows or 3D effects
- **Dashed borders** for grouping containers
- **Rounded corners** on all rectangles
- **Clear, readable text** with good contrast
- **Consistent visual language** throughout
- **Nested hierarchy** clearly visible

### AVOID:
- Dark, black, or gradient backgrounds
- Heavily saturated or neon colors
- Heavy drop shadows or 3D effects
- Cluttered layouts
- Inconsistent styling
- Complex icons or decorative elements
- Garbled or unreadable text
- Overlapping elements
