## DESIGN REQUIREMENTS

### CRITICAL: PURE WHITE BACKGROUND
- **THE FIGURE MUST HAVE A PURE WHITE BACKGROUND (#FFFFFF)**
- Use clean, solid white background for seamless integration into academic documents
- No gradient backgrounds, no dark colors, no patterns
- All figure elements should be rendered on a clean white canvas
- This ensures professional appearance in academic papers and presentations

### Visual Style
- **Professional academic aesthetic** - meeting standards of Nature, Science, or top IEEE papers
- **Clean and precise** - technically accurate representation
- **Publication-ready quality** - high precision and attention to detail

### Color Palette
Use a **professional, cohesive color scheme**:
- **Primary**: Professional Blue (#2563eb) or Academic Teal (#0d9488)
- **Secondary**: Deep Blue (#1e40af) or Green (#059669)
- **Accent**: Emphasis Orange (#ea580c) or Amber (#d97706)
- **Text/Borders**: Dark Gray (#374151) for readability
- **Background**: Pure White (#FFFFFF) (MANDATORY)

### Visual Elements
- **Rounded rectangles** or **cards** for main components
- **Professional flat icons** (FontAwesome/Material Design style) inside boxes:
  - Brain icon for AI/ML concepts
  - Gear/cog icon for processing
  - Document icon for data/text
  - Cloud icon for cloud services
  - Database cylinder for storage
  - Network/nodes icon for connections
  - Chart icon for analytics
  - Code brackets for programming
- **NO EMOJI** - Use clean vector-style icons only
- **Subtle shadows** for depth and separation (optional)
- **Flat, solid color fills** for shapes
- **Clear, bold labels** in dark text (#374151 or darker)
- **Smooth arrows** with proper arrowheads showing flow/connections

### Layout
- **Clear visual hierarchy** - most important elements are prominent
- **Logical flow** - left-to-right or top-to-bottom
- **Proper spacing** - elements are not cramped
- **Grouped related items** with subtle borders or light background fills

### Typography
- **Large, readable labels** for main components
- **Smaller annotations** for details
- **High contrast** - text is always readable
- **Sans-serif style** fonts

## FIGURE TYPES (Choose appropriate style)

### If showing a TAXONOMY/CLASSIFICATION:
- Hierarchical tree structure
- Color-coded branches for different categories
- Icons representing each category
- Cards for leaf nodes with brief descriptions

### If showing a PIPELINE/WORKFLOW:
- Sequential flow with numbered steps
- Arrows showing direction
- Different colors for different stages
- Icons inside process boxes

### If showing an ARCHITECTURE:
- Layered/stacked design
- Modular components with clear boundaries
- Connection lines between components
- Labels for each layer/module

### If showing a COMPARISON:
- Side-by-side or grid layout
- Consistent sizing for fair comparison
- Visual indicators (checkmarks, colors) for features
